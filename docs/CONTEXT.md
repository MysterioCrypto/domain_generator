# Rolling Context

Авторитетный rolling context проекта хранится на active development branch, а не дублируется на `main`.

Текущая active development branch указана в корневом `PROJECT.md`.

На момент создания этого указателя:

```text
active development branch: dev/0.2
authoritative file: dev/0.2:docs/CONTEXT.md
```

Не копировать сюда содержимое active context: это снова создаст две расходящиеся версии одной и той же рабочей памяти.
