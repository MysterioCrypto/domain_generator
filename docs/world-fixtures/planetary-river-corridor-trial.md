# P2-B2.5: необязательный испытательный речной коридор — без автоматического применения

**Исследовательский инструмент, НЕ Core и НЕ канон** — [скрипт](../../scripts/propose_planetary_river_corridor_v02.py), [исходная реальная проверка A/B/C и отрицательный результат](../reviews/p2-b2-5-real-region-corridor-negative-checkpoint-2026-11-20.md).

На настоящих A/B/C даже ограниченное углубление вдоль старой A8 D8-линии **не дало полезного улучшения**: A сильно ухудшился, B не улучшился, C не имел крупного старого выхода для проверки. Поэтому скрипт НЕ предназначен для массовой автоматической коррекции географии.

## Входы

Нужно приватно получить macro-region-source.npz из [адаптера A8/A12](planetary-geogrid-adapter.md), child-terrain-generated.npz и manifest.json из [P2-A](planetary-child-terrain.md). Core MFD диагностический алгоритм уже должен быть доступен из пакета репозитория.

Запуск из корня GitHub checkout:

```bash
python scripts/propose_planetary_river_corridor_v02.py \
  --macro-npz /private/source-A/macro-region-source.npz \
  --child-npz /private/child-A/child-terrain-generated.npz \
  --child-manifest /private/child-A/manifest.json \
  --depth-m 15 \
  --width-km 5 \
  --anchor-taper-km 2 \
  --boundary-taper-km 5 \
  --output /private/child-A/corridor-TRIAL
```

Демонстрационные числа **15 м, 5 км, 2 км, 5 км не приняты как планетарная норма**.

## Ограничения, которые проверяются программно

- Источник: **только существующие** ориентированные old A8 `river_mask` D8-сегменты; при отсутствии сегментов никаких новых рек не выдумывается.
- Только конечная отрицательная поправка высоты, ограниченная `depth_m`. Новые моря не образуются, а пиксели на границе региона сохраняются.
- Гладкая поправка математически равна 0 во **всех оригинальных макроузлах**; если нарушение обнаружено, скрипт падает.
- Проводится повторный прогон через Core MFD + геометрические lake supernodes и сравнение с исходными макровыходами, отдельно до и после вмешательства.
- Результат остаётся `P2_B2_5_OPTIONAL_NONCANONICAL_DEM_TRIAL`; даже лучший `GEOMETRICALLY_IMPROVED_ONLY` **не загружается в исходный child DEM, Core или канон**.
- Точность совпадения выходов не доказывает одинаковый бассейн, расход Q или постоянство озера. При отсутствии старого выхода результат нельзя оценить по такой метрике.
- **НЕ гарантируется seamless-продолжение** на произвольно перекрывающихся вырезках: имеется явная локальная граница затухания. Для массовых карт мира нужно отдельное тестирование перекрытий.
- Исходные приватные ZIP и картины не выгружаются в публичный GitHub.

Выходы: `noncanonical-corridor-trial.npz`, `manifest.json` и `before-after-corridor-trial.png`.
