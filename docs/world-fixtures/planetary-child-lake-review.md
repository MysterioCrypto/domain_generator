# P2-B2.1 — проверка потенциальных озёрных бассейнов

**Состояние:** предварительная диагностика в [PR #103](https://github.com/MysterioCrypto/domain_generator/pull/103). Не новая обязательная классификация биомов или озёр, не элемент принятого Core 0.2. [Причина и QA](../reviews/p2-b2-1-child-lake-basin-operator-checkpoint-2026-11-20.md).

Запустите сначала [макрогеографический адаптер](planetary-geogrid-adapter.md), затем [генератор дочернего рельефа](planetary-child-terrain.md). Оба работают с **приватными архивами пользователя** на его машине.

Из корня репозитория:

```bash
python scripts/audit_planetary_child_lakes_v02.py \
  --child-npz /private/child-A/child-terrain-generated.npz \
  --child-manifest /private/child-A/manifest.json \
  --lake-min-area-km2 4 \
  --lake-min-depth-m 2 \
  --output /private/child-A/lake-review
```

Числа 4 км² и 2 м — только **демонстрационные настраиваемые критерии** для геометрического отбора. Сравнение со строгим вариантом 16 км² и 10 м полезно для обнаружения чрезмерной чувствительности, но тоже не является утверждённым профилем Д’Акхара.

Результат: `child-lake-basin-review.png`, `child-lake-basin-review.npz`, `manifest.json`. PNG показывает высоту, **виртуальную** глубину заполнения и выделенные *кандидаты*, а не карту настоящих озёр. Отчёт различает геометрическую квалификацию, возможность геометрического перелива, неподтверждённые кандидаты, очень крупные деревья вложенных депрессий и отсутствие проверки полного water balance.

Точно проверенный маленький пример с отдельным источником из синтетической планеты: [Actions checkpoint](https://github.com/MysterioCrypto/domain_generator/actions/runs/44748762996), скачать `non-earth-geogrid-synthetic-demo`.

**Ограничения:** текущий этап inland-only, не включает морские H12 границы, не подмешивает старый A8 D8 в принятый MFD, не рассчитывает расход или сезонность озёр и не размещает магические/авторские объекты. На большой карте штатный Core lake-supernode граф ещё не применяется целиком, поэтому нет повода объявлять её речную сеть законченной.

Следующий этап P2-B2.2 — согласование доменных входов/выходов с макроречными водосборами и сборка ограниченной связной сети Core MFD+supernodes. После этого — P3 природный покров и P4 картографическая подложка.
