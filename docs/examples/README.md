# Иллюстративные примеры

Все материалы в `docs/examples/` по умолчанию являются ненормативными.

Они могут:

- показывать, как выражается конкретная задача;
- проверять выразительность `DomainSpec` и constraints;
- служить примерами для acceptance-проверок.

Они не могут сами по себе:

- добавлять обязательные типы features;
- создавать специальные случаи конкретной кампании в Core;
- менять архитектурные инварианты;
- считаться спецификацией поведения генератора.

Если идея из примера должна стать правилом Core, для неё требуется отдельное нормативное решение или изменение схемы/ADR.
