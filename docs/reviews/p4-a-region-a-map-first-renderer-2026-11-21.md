Река, озеро, дорога и город не рисуются без данных. Отдельный рендерер не заменяет P3 diagnostic sheet.

## Принципиальное ограничение

Это первый продуктовый картографический слой, но по-прежнему не законченное пространственное изображение региона. В исходных данных нет валидированной локальной 1-км MFD речной сети, водопадов, дорог, поселений; пять сюжетных точек UNPLACED, два маршрута без достоверной трассы. Не превращать старый D8 исторического A8 в принятую гидрологию Core и не придумывать реки для красоты. ImageGen может стилизовать отдельный визуальный слой, но не доказывает точность и не должен менять координаты.

Команда (из корня того же checkout):

~~~bash
python -m scripts.render_region_cartographic_base_v02 \
  --child-npz PRIVATE/child.npz \
  --child-manifest PRIVATE/child.json \
  --cover-npz PRIVATE/cover.npz \
  --cover-manifest PRIVATE/cover.json \
  --ledger-json examples/world-fixtures/osvera-first-arc-author-ledger.json \
  --pixels-per-cell 10 \
  --output PRIVATE/p4a-fresh-empty-directory
~~~

Следующий ограниченный кандидат P4-B: географически обоснованные речные/дренажные связи на текущем дочернем DEM с отдельными тестами причинности и сохранением статуса кандидата.
