# P4-D — высотные опоры и локальные альтернативы исходного рельефа (НЕ реки)

**Дата:** 2026-11-21. **Статус:** read-only evidence, НЕ каноническая география. **PR #103** Draft/Open/Unmerged, Core `dev/0.2` и frozen release не изменены.

## Задача и границы

P4-C2 показал 58 рёбер 253-звенного модельного коридора, где raw child DEM не убывает, даже если увеличить порог виртуального Priority Flood. Уточнить **почему** это произошло, не меняя исходное A8, родительские высоты, MFD или художественный рендер.

В этой ограниченной итерации выполнены ровно два связанных исследования: (1) разложение локального уклона на parent interpolation + effective fine residual при контроле расстояния до 63 географически точных высотных опор; (2) локальный спуск по исходному raw DEM как **диагностический отрицательный контроль**, чтобы не принимать наличие одного соседнего спуска за продолжение физической реки. Ранее отвергнутый D8 **НЕ возвращён** как маршрутизатор DomainData.

## Реализация

- `scripts/audit_region_anchor_alternative_drains_v02.py` — новый read-only CLI, работающий поверх исходных файлов приватного P4-B и производного P4-C2. Все исходные DEM/parent/detail NPZ остаются побитово неизменными; accepted MFD не пересчитывается. Проверяет точные SHA-256 macro NPZ, child NPZ, child manifest, P4-A map из предыдущего P4-C2 JSON и **пересчитывает из исходного raw DEM** все 253 перешедших по CSV высотные разности и максимумы виртуального заполнения. Если входные рёбра, метаданные или P4-C2 baseline не совпадают — аварийный отказ.
- `tests/test_region_anchor_alternative_drains_v02.py` — 17 отдельных синтетических тестов: parent-versus-detail attribution, координаты высотных опор без округления к пикселям, порча source-хеша, разрыв маршрута, неверный threshold, несуществующие anchors, несовпадение исходного перепада, детерминированный PNG/CSV/JSON replay, отсутствие auto water inference.
- В geogrid workflow добавлена P4-D стадия после P4-C2 и регистрация тестов. На синтетическом регионе с одним подтверждённым модельным маршрутом запускается полный CLI; если референсная синтетическая вырезка вообще не содержит релевантного A8 входа, это честно отмечается, а полный positive/negative CLI всё равно тестируется отдельной самостоятельной toy-fixture.

### Нормативно важные технические различия

Опоры — **63 непрерывных географических координаты родительских DEM-узлов**, не 63 совпадающих 1-км пикселя. Расстояние измеряется от центра звена до ближайшей parent station в принятой сферической локальной системе координат `spherical_xyz_v1`. Формула получения станций воспроизводит принятую геопривязку исходного child generator.

Для каждого ребра:

```text
delta_raw_z = child_z[target] - child_z[source]
delta_parent_z = parent_interpolated_z[target] - parent_interpolated_z[source]
delta_fine_effective = delta_raw_z - delta_parent_z
```

Последняя величина — **эффективный residual**, равный local noise в обычной суше, но не обязательно равный исходному `new_local_relief_m` при coastal clamping; так нельзя ошибочно приписать всю разницу только noise. Все вычисления проводятся на уже сохранённом `float32` child DEM.

Рассматривается строгое снижение высоты `target < source` у **сырого** DEM. Экспериментальный greedy raw-descent шаг выбирает соседнюю ячейку с максимальной положительной крутизной спуска, затем повторяет до физического края вырезки или локального минимума. Это **не MFD, не ручей, не true basin, не Lake, не доказательство drainage connectivity**. В частности, локальная впадина и `Priority Flood fill` не являются подтверждением воды.

## Результаты на PRIVATE Осве́ра, регион A

Исходные SHA-256 A8 `6824ccf2a4aea7b2514a4e694e84ad13fd3ff4e18dba6c3be6b4b7753dc019ec`, A12 `db9f0f91fca845058c658dfdd639c882b9cf0514736b3677184a4c84ff20b3a4` подтверждены в предшествующем P4-B. В текущей итерации используются **уже извлечённые приватные производные NPZ**, оригинальные A8/A12 ZIP не загружались и не пересчитывались. Сама P4-D заново сверила SHA-256 с предыдущим P4-C2 и перепроверила `253 = 181 strict + 14 fill-only + 49 raw-uphill-only + 9 both`.

| Параметр | Результат |
| --- | ---: |
| Исходные parent height anchors внутри child | **63** (9×7), continuous coordinates |
| Рёбра без убывания raw child DEM | **58** |
| Parent interpolated уклон спускался, но local effective residual его обратил | **56 / 58** |
| Сам parent interpolated уклон не спускался | **2 / 58** |
| Есть хотя бы один **соседний** raw-downhill альтернативный первый шаг | **46 / 58** |
| Нет даже соседнего raw-downhill шага | **12 / 58** |
| Raw greedy negative-control от всех 58 мест завершился локальной впадиной | **58 / 58** |
| Raw greedy negative-control добрался до границы региона | **0 / 58** |
| Медиана расстояния до ближайшей parent-anchor: raw-uphill | **13.923 км** |
| Медиана расстояния до ближайшей parent-anchor: strict | **12.585 км** |
| Raw-uphill в пределах 6 км от опоры | **3 / 58** |
| Strict в пределах 6 км от опоры | **23 / 181** |
| Число непрерывных групп подряд идущих raw-uphill звеньев | **31** |
| Самая длинная группа подряд | **5 звеньев** |
| Автоматически добавленная A8 площадь | **0 км²** |

**Что доказано:** основная локальная причина неблагоприятных перепадов на данном выбранном коридоре — несогласование *parent* descent и *fine effective residual* при детализации (56/58). Положение проблемных сегментов не показывает простого скопления непосредственно вокруг закреплённых parent stations. Даже альтернативный первоначальный raw-downhill спуск не обеспечивает непрерывного raw-D8 выхода — все 58 отрицательных диагностических проб приходят к математическим локальным минимумам.

**Чего НЕ доказано:** статистическая географическая причинность связи с parent anchoring на множестве разных миров, необходимость выкапывать 58 русел, истинность старого A8 бассейна, реальность озёр у локальных минимумов, отсутствие groundwater/infiltration/baseflow, perennial flow, Q, watershed equality. Наблюдение локальных минимумов raw DEM само по себе **не означает**, что accepted Priority-Flood MFD ошибочен: его назначение — обслуживать депрессии, и диагностический отказ raw D8 ожидаем в такой геометрии.

## Следующий ограниченный продуктовый шаг — P4-E

Готовить **управляемое сравнение нескольких неканонических вариантов мелкого рельефа** из *тех же* родительских опор (например `relief_strength` или отдельная valley-conditioned функция), с учётом внешнего макроскопического basin contract; считать число raw-gradient reversals, устойчивость высотных опор, дендритность и качество видимой карты. Подавлять локальный шум всей планеты или вписывать старый A8/D8 в MFD вручную без такого сравнения нельзя. Нужен операторский просмотр **реально различающихся** карт; не требовать формального одобрения этой диагностической промежуточной карты.
