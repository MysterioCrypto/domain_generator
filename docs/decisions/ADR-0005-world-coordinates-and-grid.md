# ADR-0005 — Мировые координаты и raster grid

## Контекст

Пользовательские spatial constraints должны читаться как обычная карта, а внутреннее raster storage не должно протекать в публичный контракт.

## Решение

- начало мировых координат: юго-запад;
- `+x`: восток;
- `+y`: север;
- пользовательская геометрия задаётся в километрах или нормализованных координатах;
- `DomainSpec` использует `width_km`, `height_km`, `cell_size_km`;
- raster использует `row/column` только внутри слоя Grid/field;
- `row 0` соответствует северной строке raster;
- преобразование world ↔ raster централизовано в `Grid`;
- размеры domain в Core 0.1 должны делиться на `cell_size_km` без остатка.

## Следствия

Направления, видимые пользователю, остаются естественными (`southwest -> northeast` означает диагональ вверх-вправо), а индексирование NumPy/image изолируется как техническая деталь.
