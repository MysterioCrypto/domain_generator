# ADR-0003 — Детерминированность и независимые RNG-потоки

## Контекст

Один глобальный поток `random()` делает генерацию хрупкой: добавление нового случайного шага в растительность может изменить горы, реки и все последующие результаты.

## Решение

Использовать корневой seed и производные RNG-потоки по стабильным идентификаторам стадий и подзадач, например `derive_seed(root_seed, stage_id, feature_id, attempt_id)`.

## Гарантия

В поддерживаемой среде одинаковые `DomainSpec + root seed + generator version` должны воспроизводить одинаковый `DomainData`.

## Следствия

- Изменение одной стадии не обязано перетасовывать случайность всех остальных.
- Debug и regression tests становятся воспроизводимыми.
- Номер candidate attempt входит в детерминированное пространство seed, а не является внешним случайным событием.
