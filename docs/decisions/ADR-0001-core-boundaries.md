# ADR-0001 — Границы Core

## Контекст

Проект должен переживать смену чатов, интерфейсов и инструментов. Если процедурная логика зависит от ChatGPT, GitHub Actions, конкретного renderer или лора кампании, её трудно тестировать, переносить и переиспользовать.

## Решение

Core принимает формальные данные и возвращает формальные данные. Вызовы LLM, GitHub orchestration, художественная стилизация и campaign-specific lore находятся за его границей.

## Следствия

- Core можно запускать локально, в CI или из будущего сервиса без переписывания алгоритмов.
- Интеграционные слои могут меняться независимо.
- Специфичные для сеттинга расширения должны быть отделены от базового генератора.
- Renderer не является источником истины о мире.
