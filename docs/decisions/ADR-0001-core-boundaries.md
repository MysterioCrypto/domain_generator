# ADR-0001 — Границы Core

## Контекст

`domain_generator` должен быть самостоятельным процедурным ядром, пригодным для разных миров, жанров, кампаний, игровых систем, приложений и способов визуализации. Если процедурная логика зависит от конкретного сеттинга, лора кампании, ruleset, UI, renderer, LLM или сервиса orchestration, генератор становится трудно тестировать, переносить и переиспользовать.

Термин `Domain` в проекте используется только в общем пространственном смысле: ограниченная область мира или карты, которая генерируется как единое целое. Он не обозначает лоровую сущность какого-либо конкретного мира.

## Решение

Core принимает формальные данные, не зависящие от конкретного сеттинга, и возвращает такие же формальные данные.

Внутри Core допустимы универсальные пространственные понятия: geometry, terrain, hydrology, continuous fields, networks, constraints, procedural features и placement rules.

За границей Core находятся:

- конкретные сеттинги и лор кампаний;
- конкретные игровые системы и их rulesets;
- каталоги пресетов конкретных сеттингов и данные мира;
- orchestration LLM/агентов;
- orchestration GitHub/CI;
- UI, renderer, художественная стилизация и логика представления.

Внешний потребитель конкретного сеттинга может компилировать собственные понятия в публичные универсальные контракты Core, но Core не должен знать имя или семантику этого потребителя.

## Следствия

- Один и тот же Core можно использовать для fantasy, science fiction, survival, strategy, simulation и других задач world generation без изменения алгоритмов.
- Конкретный сеттинг или кампания являются потребителем `domain_generator`, а не архитектурным родителем Core.
- Presets, adapters и пакеты контента конкретных сеттингов должны жить вне базового пакета Core либо в явно внешнем extension layer.
- В Core не добавляется поле `setting` только ради идентификации внешнего мира: если такая metadata нужна приложению, она принадлежит внешнему слою.
- Интеграционные слои могут меняться независимо.
- Renderer не является источником истины о мире.
